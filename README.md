# Melody

Melody is a premium Text-to-Speech (TTS) studio created by **VoidStation**. It provides an advanced, seamless experience for generating high-quality voiceovers using state-of-the-art TTS models.

## Features

- **Batch Processing**: Import multiple text files (or entire folders) and process them sequentially with custom speeds.
- **Drag-and-Drop Reordering**: Easily reorder your scripts before generation to maintain narrative flow.
- **Per-Item Speed Control**: Configure different reading speeds (0.5x to 2.0x) for each individual text segment.
- **Premium UI/UX**: Enjoy a sleek, modern interface with beautiful micro-interactions, dark mode, and seamless workflow.
- **Live Queue Management**: Track your generation progress in real-time with our detailed job queue sidebar.

## Setup

1. Install dependencies:
   ```bash
   pnpm install
   ```

2. Start the API server:
   ```bash
   pnpm dev:api
   ```

3. Start the Web client:
   ```bash
   pnpm dev:web
   ```
